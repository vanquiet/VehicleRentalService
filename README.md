# Vehicle Rental Service

## About
This is our final project for the SoftwareDesign Patterns course.
It is a simple console program in Java for renting a car, a bike or a van.

## Features
- rent a vehicle by hours or by days
- add extras: insurance, GPS, child seat
- get a message when a rented vehicle is free again

## Design Patterns
- Factory - creates vehicles (car, bike, van)
- Observer - sends messages to customers
- Strategy - hourly and daily price
- Builder - creates a rental order
- Decorator - adds extras to the order
- Facade - one simple class for the whole system
